This popup only displays the log; the measurement itself runs continuously in a hidden chrome.offscreen document that exists independently of this popup, any tab, and any window. Closing this popup does not stop it — reopen the extension's icon any time to see what has accumulated.

How to use this extension

  1. Load it unpacked (see this folder's README), then open this popup once to confirm rows are appearing.
  2. Close the popup. There is no tab or window to move — the whole point of chrome.offscreen is that this measurement does not belong to one.
  3. Leave Chrome running in the background: switch to a different application so Chrome itself is not the frontmost app, for a few minutes.
  4. Reopen this popup and compare the timer drift and CPU benchmark rows logged while Chrome was backgrounded against the ones logged while it was frontmost.
