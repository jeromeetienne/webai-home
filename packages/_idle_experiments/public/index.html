WebAI / idle-time experiments

What does a browser tab
actually do when it is idle?

Small, self-contained pages that measure what Chrome does to a tab's timers, animation frames, and raw compute speed as it moves between focused, visible-but-unfocused, and backgrounded. Each page runs on its own, with no server and no connection to the rest of this repository.

01 Visibility & timer calibration log Logs visibility state, focus state, timer drift, animation-frame rate, and raw CPU throughput over time. Open experiment ↗ 02 Qwen3-0.6B generation log Runs the same real ONNX Runtime Web model over and over, logging each generation's speed against this tab's visibility and focus. Open experiment ↗ 03 Web Worker CPU offload log Runs the same fixed CPU workload on the main thread and on a dedicated Worker at the same time, so the two can be compared directly. Open experiment ↗ 04 Silent audio trick log Same calibration measurement as experiment 01, plus a very quiet continuous tone, to test the audio-keeps-a-tab-active trick. Open experiment ↗
05 Offscreen audio trick log A real, local-only Chrome extension using chrome.offscreen, so there is no tab at all — not opened as a page. See its own README to load it. extension/offscreen_audio_log/README.md
06 WebRTC data channel trick log Same calibration measurement as experiment 01, plus a loopback WebRTC data channel between two peer connections in this same page, to test the real-time-connection exemption. Open experiment ↗

Nothing here downloads a model or talks to a server. Every measurement stays in the page.
